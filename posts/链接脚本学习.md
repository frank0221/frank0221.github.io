# 链接脚本学习

链接脚本是告诉链接器如何将编译后的代码和数据放到内存中的配置文件。

## MEMORY 块: 定义物理内存区域

```makefile
MEMORY
{
  名称 (属性) : ORIGIN = 起始地址, LENGTH = 大小
}
```

- r = readable (可读)
- w = writable (可写)
- x = executable (可执行)
- ! = 反转属性

## SECTIONS 块 - 定义段的放置规则

```makefile
SECTIONS
{
  段名称 :
  {
    内容规则
  } >目标内存区域 AT>加载地址
}
```

## 语法结构

### 入口

- ENTRY(Reset_Handler)

### 段定义

- `*(.text)`：匹配所有输入文件中的 `.text` 段
- _stext = .;             *定义段开始符号*
- _etext = .;             *定义段结束符号*

## 位置计数器点号 `.`

`.` 是链接脚本中的位置计数器（Location Counter），表示当前的内存地址位置。

可以把它理解成一个指针，指向当前正在安排内容的地址。链接器在处理 `SECTIONS` 时，会随着内容的放置不断推进这个位置。

### 示例

```ld
SECTIONS
{
    .text 0x08000000 :
    {
        . = ALIGN(4);     /* 确保当前地址按 4 字节对齐 */
        *(.text)          /* 放置所有 .text 内容 */
        . = ALIGN(4);     /* 段结束前再次对齐 */
    } > FLASH
}
```

上面这段的含义是：

- `.text` 段从 `0x08000000` 开始放置
- `. = ALIGN(4)` 会把当前位置调整到 4 字节边界
- `*(.text)` 会把所有输入文件中的 `.text` 段内容放进来
- 最后再次对齐，便于后续段继续按对齐要求放置

### 常见写法

| 写法 | 含义 | 结果 |
| --- | --- | --- |
| `. = 0x1000` | 把当前位置直接设置为 `0x1000` | 当前地址变为 `0x1000` |
| `. = . + 100` | 让当前位置向前移动 100 字节 | 预留 100 字节空间 |
| `. = ALIGN(4)` | 把当前位置对齐到 4 字节边界 | 地址变为 4 的倍数 |
| `. = ALIGN(0x100)` | 把当前位置对齐到 256 字节边界 | 地址变为 `0x100` 的倍数 |
