# Python 绘图笔记：Matplotlib 简明指南

本笔记记录常用 Python 绘图库的用法、示例与实战技巧，适合数据分析和可视化学习与参考。

## Figure 与 Axes（画布与坐标系）

Figure（画布/画框）：
这是整个图片的容器。你可以把它想象成一张白纸，或者一个相框。
它决定了图片的物理尺寸（比如 A4 纸大小，还是邮票大小）。
代码通常对应：fig

Axes（坐标系/图表）：
这是画在画布上的具体内容。一张画布上可以画一张图，也可以画四张图。
它包含了横轴、纵轴、刻度、柱子、线条等所有数据元素。
注意：这才是你真正“绘图”的地方。

示例代码（已修正 figsize）：

```python
import matplotlib.pyplot as plt

categories = ['A', 'B', 'C']
values = [10, 25, 15]
# --- 1. 创建画布 ---
# 这行代码的意思是：请给我一个画布和默认的一个坐标系
# figsize=(宽, 高)：这是调节比例的第一道关卡
# 宽高比建议 4:3 或 5:4，这是科研期刊的黄金比例
fig, ax = plt.subplots(figsize=(4, 3))

ax.bar(categories, values, width=0.6, color='#4472C4')
plt.show()
```

## set_ylim,spines和tick_params

set_ylim（上下留白）
默认图表中，最高的柱子或最大点常常贴着“天花板”。用 `set_ylim` 手动扩展 Y 轴范围可以留出视觉上的空白，让图看起来更舒服：

示例：在已有数据上下各留 10% 空白

```python
# 假设 values 为已有的 y 值列表
 ymin, ymax = min(values), max(values)
 margin = 0.1 * (ymax - ymin)
 ax.set_ylim(ymin - margin, ymax + margin)
```

spines（边框控制）
科研风格常常去掉上边框和右边框，称为“断臂”风格，这样视觉上更简洁，焦点在数据上：

```python
# 隐藏上、右两个边框
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)

# 可选：把底部和左侧的 spine 略微外移以避免刻度遮挡（可选）
ax.spines['bottom'].set_position(('outward', 2))
ax.spines['left'].set_position(('outward', 2))
```

tick_params（刻度控制）
使用 `tick_params` 可以控制刻度线的方向、长度、宽度和标签大小，快速统一刻度样式：

```python
# 统一主要刻度的大小、方向和长度
ax.tick_params(axis='both', which='major', labelsize=10, length=6, width=1.0, direction='out')

# 如果只想在底部和左侧显示刻度（配合断臂风格）
ax.xaxis.set_ticks_position('bottom')
ax.yaxis.set_ticks_position('left')
```

## 多组数据的柱状图

在画多组柱状图时，X 轴不再是简单的 ['A', 'B', 'C']（直接用类别标签），而是用一串数值坐标来放置每组柱子。

原理：每一组数据都需要在 X 轴上占据一个特定的位置。通常我们使用 numpy 生成基础刻度位置（例如 [0, 1, 2]），再通过加减柱子宽度的一半来实现左右错位，使多组柱子并排显示。

步骤演示（两组数据的错位逻辑）

```python
import matplotlib.pyplot as plt
import numpy as np

# 1. 准备数据
categories = ['Control', 'Drug A', 'Drug B']
values_1 = [20, 35, 30]  # 第一组数据（例如：Male）
values_2 = [25, 32, 34]  # 第二组数据（例如：Female）

# 2. 生成 X 轴坐标序列 -> [0, 1, 2]
x = np.arange(len(categories))

# 3. 设定柱子宽度
width = 0.35  # 每根柱子宽 0.35，两组并排宽度合计 0.7，留有间隙

# 4. 创建画布
fig, ax = plt.subplots(figsize=(6, 4))

# 5. 绘制第一组 (位置 = x - width/2，即向左偏移半个身位)
ax.bar(x - width/2, values_1, width, label='Male', color='#4472C4')

# 6. 绘制第二组 (位置 = x + width/2，即向右偏移半个身位)
ax.bar(x + width/2, values_2, width, label='Female', color='#ED7D31')

# 7. 修复 X 轴刻度标签（把数字刻度替换为类别文字）
ax.set_xticks(x)
ax.set_xticklabels(categories)

# 额外：美化（可选）
ax.set_ylabel('Value')
ax.set_title('Grouped bar chart — two groups')
ax.legend()

plt.tight_layout()
plt.show()
```

说明小结：
- 使用 `np.arange` 建立基础的 x 坐标。每个类别对应一个整数位置。
- 通过对 x 加上或减去 `width/2`（或更多偏移，当有多于两组时使用 `width * i` 的策略）来让柱子并排而不重叠。
- 绘图后把 x 刻度替换成类别标签（`ax.set_xticks` + `ax.set_xticklabels`），否则刻度仍是数字索引。

## 三组及以上数据怎么办？

当组数达到 3 组或更多时，手动计算每组的偏移容易出错。推荐使用循环绘图：

核心逻辑：预先定义颜色列表，动态计算每组柱子的宽度和偏移位置，循环绘制并可带误差条。


精简示例：

```python
import matplotlib.pyplot as plt
import numpy as np

categories = ['Sample 1', 'Sample 2', 'Sample 3']
data_groups = {
    'Type A': [10, 20, 15],
    'Type B': [12, 18, 22],
    'Type C': [8, 25, 18]
}
errors = {
    'Type A': [1, 2, 1],
    'Type B': [1.5, 1.5, 2],
    'Type C': [1, 2, 1.5]
}

# 推荐色盘
colors = ['#4472C4', '#ED7D31', '#A5A5A5']

x = np.arange(len(categories))
n_groups = len(data_groups)
# 动态宽度：把总可用宽度（例如 0.6）均分给每组
width = 0.6 / n_groups

fig, ax = plt.subplots(figsize=(6, 4))

for i, (label, values) in enumerate(data_groups.items()):
    # 计算对称偏移：i 从 0..n_groups-1
    pos = x + (i - (n_groups - 1) / 2) * width
    ax.bar(pos, values, width,
           yerr=errors[label],
           label=label,
           color=colors[i % len(colors)],
           edgecolor='black', linewidth=0.8, capsize=3)

# 美化
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)
ax.yaxis.grid(True, linestyle='--', alpha=0.4, zorder=0)
ax.set_xticks(x)
ax.set_xticklabels(categories)
ax.legend(frameon=False)

plt.tight_layout()
plt.show()
```

要点小结：

- width 动态计算以避免重叠；总宽度（0.6）可根据需要调整。
- 偏移公式 (i - (n_groups-1)/2) * width 保证各组对称排布。
- 循环法便于扩展到任意组数，并可在循环内添加误差条、数值标签或不同样式。

## 图例（legend）——怎么画、放哪儿、常用参数

图例用于说明每个图形元素对应的含义（例如分组名、颜色或线型）。在 Matplotlib 中，常用做法是：在绘图函数里通过 `label='名字'` 指定标签，然后调用 `ax.legend()` 来显示图例。

常用参数与技巧：

- `loc`：图例预设位置（'best', 'upper right', 'upper left' 等）。
- `bbox_to_anchor`：配合 `loc` 精确放置（常用于把图例放到图外）。例如 `loc='upper left', bbox_to_anchor=(1.02, 1)` 会把图例放在右侧图外。
- `frameon` 或 `framealpha`：控制图例边框与透明度，例如 `frameon=False` 常用于科研风无边框风格。
- `ncol`：设置图例列数，适合把图例横向排列以节省垂直空间。
- `fontsize`、`title`：控制文字大小与图例标题。
- `handlelength`、`handletextpad`、`markerscale`：控制图例里符号和文字的相对距离与大小，细调外观。

示例 1 — 简单默认图例（已在绘图时设置 label）：

```python
# 假设之前绘图时已经给每个系列设置了 label
ax.plot(x, y1, label='Series 1')
ax.plot(x, y2, label='Series 2')
ax.legend()
```

示例 2 — 把图例放到图外右侧（适合图形窄但图例多的情况）：

```python
ax.legend(loc='upper left', bbox_to_anchor=(1.02, 1), borderaxespad=0, frameon=False)
```

示例 3 — 多列图例并设置标题与字号：

```python
ax.legend(ncol=2, title='Groups', fontsize=10, title_fontsize=11, frameon=False)
```

在分组柱状图中（我们上面的例子已经在 `ax.bar(..., label=...)` 中设置了标签），常见做法是把图例放到图外或置于图上方以避免遮挡：

```python
# 在三组/多组柱状图例子里：
ax.legend(frameon=False, loc='upper left', bbox_to_anchor=(1.02, 1))
plt.tight_layout()  # 注意：在把图例放到图外时仍应调用 tight_layout
```

补充：如果你希望自定义图例的顺序或仅显示部分图例，可以使用 `handles, labels = ax.get_legend_handles_labels()` 手动调整顺序后再调用 `ax.legend(handles, labels)`。
