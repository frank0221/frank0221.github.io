# 关于这个项目 🛠️

这个项目的初衷是提供一个**极简**但**视觉效果出色**的个人主页模板。

## 技术栈

| 技术 | 用途 |
| --- | --- |
| **Vue 3** | 响应式状态管理 |
| **Marked** | Markdown 解析 |
| **Highlight.js** | 代码语法高亮 |
| **CSS3** | 动画与玻璃态效果 |
| **Canvas** | 星空背景绘制 |

## 自定义

你可以随意修改 `css/style.css` 中的变量来调整颜色主题：

```css
:root {
    --accent-color: #ff0055; /* 改成粉色 */
}
```
