# 关于这个站点

这是我的个人 GitHub Pages 主页，用来展示个人简介、学习方向、阶段性成果和技术随笔。

## 设计方向

这次重构把旧版星空玻璃态博客改成更接近 Apple 官网的风格：

- 更大的留白与更清晰的内容层级
- 浅色背景、系统字体和简洁导航
- 产品页式首屏，用一个芯片卡片概括技术方向
- 文章区保留搜索、分类筛选和 Markdown 阅读能力

## 技术实现

| 技术 | 用途 |
| --- | --- |
| HTML | 页面结构 |
| CSS | 视觉、布局与响应式适配 |
| JavaScript | 文章筛选、加载与 Markdown 渲染 |
| GitHub Pages | 静态部署 |

项目不依赖 Node.js 构建流程，推送到仓库后即可由 GitHub Pages 部署。
